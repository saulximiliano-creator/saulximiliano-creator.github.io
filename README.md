# Portafolio personal

Sitio web personal hecho con **HTML y CSS puro** (sin frameworks), responsivo y publicado con **GitHub Pages**.

- Diseño oscuro con variables CSS
- Layout con Flexbox y CSS Grid (`auto-fit` + `minmax`) que se adapta a celular sin media queries complejas
- Navegación con anclas y scroll suave
